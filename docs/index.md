## Objetivo

O objetivo principal é garantir uma boa qualidade de prototipagem com o mínimo de iterações possíveis, assegurando o bom uso dos recursos e a qualidade final do protótipo. Para tal, o site contém um guia prático para prototipagem eletrônica utilizando as ferramentas disponíveis no GCOM. Aqui se encontra regras de projeto, boas práticas e procedimentos de manufatura que auxiliam no comprimento deste objetivo principal.
